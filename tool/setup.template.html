取り込み用ブックマークの登録

単位ハーネス(筑波大学の学生向け非公式ツール)。1回だけ行えば、次からは実行するだけです。

このブックマークがすること

  • ログイン済みの TWINS / manaba のページ上で、時間割表・未提出課題の表だけを読み取り、単位ハーネスに渡します。
  • パスワードには触れません。大学のサイトは読むだけで、履修登録・取消・提出などは一切しません。
  • 読み取ったデータは URL の「#」以降でこのブラウザ内の単位ハーネスに渡り、サーバーには送られません。

中身は ソースコード で確認できます。

パソコン(Chrome / Edge / Safari)

下のボタンをブックマークバーにドラッグしてください。

単位ハーネスに取り込む

iPhone(Safari)

  1. 画面下の 共有ボタン → 「ブックマークを追加」。名前を 単位ハーネスに取り込む にして保存。
  2. 下の「コードをコピー」を押す。
  3. ブックマーク(本のアイコン)→ 編集 → いま追加したブックマークを選び、アドレス欄を全部消してから貼り付け → 完了。

コードを表示

使うとき: TWINS / manaba のページで ブックマーク(本のアイコン)→「単位ハーネスに取り込む」 をタップします。
単位ハーネスは「ホーム画面に追加」せず、Safari のブックマークから開いてください(ホーム画面版はデータが別になるため)。

Android(Chrome)

  1. メニュー(︙)→ ☆ でこのページをブックマークし、「編集」で名前を 単位ハーネスに取り込む にする。
  2. 「コードをコピー」を押し、ブックマークの URL 欄を全部消して貼り付けて保存。

コピーしました

使うとき: TWINS / manaba のページでアドレスバーに「単位ハーネス」と入力し、候補に出るブックマークをタップします(ブックマーク一覧から開いても動きません)。

使い方

  1. 時間割: TWINS にログインし「履修登録・登録状況照会」を開いてブックマークを実行。全学期を読み込み、自動で単位ハーネスに戻ります。
  2. 課題: manaba にログインした状態(どのページでも可)でブックマークを実行。
